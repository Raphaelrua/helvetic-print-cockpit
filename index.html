Damit es alle sehen

Nach dem Hochladen sind die neuen Zahlen zuerst nur in deinem Browser. Veröffentlichen geht auf zwei Arten:

  • Direkt: Einmal einen GitHub-Token eintragen (siehe unten), dann «Für alle veröffentlichen» klicken.
  • Von Hand: «daten.json herunterladen» und im Repo über Add file → Upload files hochladen.
GitHub-Token einrichten
  1. Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → helvetic-print-cockpit.
  3. Permissions → Repository permissions → Contents: Read and write. Generate token und kopieren.
  4. Hier einfügen. Der Token bleibt nur in diesem Browser gespeichert.

Definitionen und Quellen
  • Ampel «hoch ist gut»: grün ab Ziel, gelb ab 95 % des Ziels. «Tief ist gut»: grün bis Ziel, gelb bis Ziel plus Toleranz. Auslastung (Band): grün 95–100 %, gelb 90–110 %.
  • Absatz gesamt = Markt 1 plus Grossabnehmer. Nicht gedeckte Nachfrage = potentieller minus tatsächlicher Absatz (Marktforschungsbericht).
